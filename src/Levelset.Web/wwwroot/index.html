Levelset

Paste the address of a site and see how ready it is for AI agents. You get a score out of 100, and for every finding a fix you can copy.

What it looks at

  • WebMCP tools the page registers: names, descriptions, schemas and whether risky tools are marked.
  • An MCP server, if the site has one: that it answers, lists tools well and rejects foreign origins.
  • An x402 payment challenge, if the site charges: that it is well formed and priced sensibly.
  • llms.txt, robots.txt, a sitemap, markdown for agents, structured data and basic hygiene.

The check only reads. It never runs a tool, submits a form or sends a payment. The check is free and needs no account. About Levelset.
